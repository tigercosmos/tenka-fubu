## ⚔️ 這是什麼

《天下布武》是一款**純瀏覽器、單機、全繁體中文**的戰國大戰略遊戲。
你扮演一位戰國大名，在整個日本的版圖上分封知行、開發領國、調略人心、締結姻盟、出陣合戰——
最終一統天下。玩法向《信長之野望·新生》致敬，機制則全部重新設計。

## ✨ 核心特色

- 🏯 **知行與家臣自主** — 你不必微管理每一塊土地。把郡分封給武將，他們便自主治理、開發、成長；你只需掌握大方向。
- 🗾 **即時天下大勢** — 全日本地圖上，各勢力同時即時行動（可暫停、變速 ×1／×2／×5）。戰線推移與勢力消長，一目瞭然。
- 💥 **威風的爽快感** — 打贏一場關鍵合戰，鄰近敵郡望風而降、敵城士氣崩落，戰線一口氣大幅推進。
- 🎎 **武將是資產** — 登用、育成、任命、忠誠、引拔與叛服……六階身分與功績累積，是長期經營的核心。
- 📜 **歷史沉浸** — 桶狹間、川中島、本能寺（條件式）等史實事件；朝廷官位、室町幕府，與戰國語感的繁中文本。

**系統一覽**：內政（郡開發／知行／城下施設／政策／徵兵／輸送／治安一揆）· 軍事（編成出陣／行軍／制壓／野戰自動解算／合戰戰術戰場／戰法／威風／攻城／軍團／兵站）· 外交（外交工作與信用／同盟／婚姻／停戰／從屬）· 朝廷與幕府（官位八階／役職五階）· 調略（引拔／流言／內應）· 具申（家臣提案）· 歷史事件與大命 · 勝敗判定與結局 · 存讀檔。

## 🤖 願景：讓 AI 執掌天下

**這才是本作的核心野望。** 從第一行架構就為 AI 而設計。

遊戲核心是一個**純粹、確定性的狀態機**：

```
(遊戲狀態 GameState, 指令 Command[]) ──每日 tick──▶ 新狀態 + 事件 GameEvent[]
```

不論是人類玩家還是 AI，操作一位大名的**唯一方式都是送出指令（Command）**。於是：

- 🧠 **每一位大名，都能交給 AI 操盤。** 正常遊戲由你執掌一家，其餘四十家由 AI 經營。Node 模擬器提供全 AI 模式；這不表示畫面已有完整旁觀模式。
- 🎭 **每家 AI 都有性格（AiPersona）**：征服者、守成者、謀略家……不同性格帶來不同的擴張、外交與用人風格；委任的城主、領主、軍團也各有其代管 AI。
- 🔬 **內建無頭模擬器（`tools/simulate.ts`）**：不開畫面、全 AI 跑上數十年，輸出各家石高曲線——既用來驗證平衡，也讓你回看「如果沒有你，歷史會怎麼走」。
- 🚀 **未來展望**：因為決策層（`AiIntent`）與規則層乾淨分離，大名的「大腦」可以整顆抽換成更強的 AI——**甚至接入大型語言模型（LLM）**，讓每位大名成為會權衡、會結盟、會背叛、有獨立性格的智能體。屆時，這張戰國地圖就是一座 AI 的競技場。

## 🛠️ 技術架構

- **前端**：TypeScript（strict）＋ React 18 ＋ Vite；狀態管理 Zustand；戰略與合戰地圖使用 **PixiJS 8（WebGL）**。效能驗收必須註明 workload、硬體與 renderer backend。
- **背景模擬與 Rust／WASM**：每日策略結算在專用 Web Worker 執行，與主頁渲染平行；日與日之間仍串行，保留指令與 RNG 順序。Rust 提供路徑搜尋、地理標籤評分及城名牌布局；其餘每日系統仍使用 TypeScript。主頁布局使用獨立 WASM 實例。架構契約見 [01 D22](plan/01-architecture.md)，實測與未通過項目見 [驗證紀錄](docs/validation/2026-10-12/completion-audit/README.md)。
- **純前端 SPA、零後端**，可直接部署到 GitHub Pages。存檔走 IndexedDB（idb-keyval）＋ lz-string 壓縮。
- **核心鐵律**：`src/core/` 是零 DOM 依賴的純邏輯，能在 Node 裡跑測試與模擬；**決定論設計**（固定亂數流），同劇本同種子必重現同一結果——這也是 AI 對戰可重播、可驗證的基礎。
- 全 UI **繁體中文（台灣慣用語）**，字形嚴禁簡體與日文新字體。

- **平衡分布驗證**：模擬器分列 15 §5.6 的 `balanceAcceptance` 與 18 §5.4 的 `acceptance`。`--verify-repeat=true` 使用獨立重跑；`--continue-on-error=true` 與明定 output 保留全部失敗種子。最新 runtime 的 easy／normal／hard 各二十種子、二十五年診斷全部因 ownership 違例停止。六十種子均保留失敗，零項完整 run／repeat，沒有 INV13；CSV 僅有標頭，`repeatCsvEqual=null`。兩個 gate 均 incomplete，不宣稱平衡或決定論通過。
- **Heap 界線**：修補前二十次 remount 的原 renderer／Application ID 已消失，圖像與字型 cache 計數相同，但 post-GC heap 增加 854,608 bytes。現在固定 Pixi 8.19.0 並加入 hash-guarded 本地修補；七十三項 focused 測試通過。修補後 native remount、GPU pixel 與整體穩態尚未驗證，heap gate 仍未通過。

## 本機執行

使用 Node 22 與 npm。

```sh
npm ci
npm run dev
```

正式建置與預覽：

```sh
npm run build
npm run preview
```

工具命令與結果必須分開記錄。`npm test` 保留全國 golden 與已知失敗，不代表目前會全綠。

```sh
npm run typecheck
npm run lint
npm test
npm run validate:data
npm run test:coverage:report
```

`npm run test:perf` 必須獨立執行，不與 browser 或其他重型測試同時量測。
CI 的 core 覆蓋率與 perf 門檻自 M9 起阻斷；目前 M6 保留報告。
一般單元失敗仍阻斷 CI；獨立全國 golden 保留自己的里程碑門檻。

## 操作參考

從標題選擇「新遊戲」、劇本及大名。點選地圖城池、郡或部隊，使用情境操作與面板。
支援視窗下限為 1280×720 CSS px；視窗過小會阻擋操作並暫停，不會自動恢復速度。
目前驗收使用桌面 Chromium；未宣稱手機或其他瀏覽器通過驗收。

| 按鍵                 | 操作與條件                                                                     |
| -------------------- | ------------------------------------------------------------------------------ |
| Space                | 暫停／恢復；合戰使用自己的速度，不推進策略日曆                                 |
| 1／2／3              | ×1／×2／×5；輸入框或對話框擁有焦點時不執行全域快捷鍵                           |
| F1／F2               | 內政／出陣                                                                     |
| F3／F4／F5           | 外交／武將／政策；F5 不是快速存檔                                              |
| F6／F7               | 軍團／大命                                                                     |
| R                    | 報告中心                                                                       |
| WASD／方向鍵、＋／－ | 地圖平移／縮放；只在地圖背景焦點下操作                                         |
| Home／M              | 選擇並聚焦本城／顯示或隱藏小地圖；只在地圖背景焦點下操作                       |
| Alt+1…5／Tab         | 五種分析主題／勢力主題；面板、原生控制項與對話框焦點保留自己的操作             |
| Esc                  | 輸入框先離開焦點；之後依對話框、面板、選取與系統選單的擁有者處理，不是撤退指令 |
| Ctrl+S／⌘S、F9       | 策略畫面快速存檔／快速讀檔；對話框、輸入期間與合戰停用                         |

系統選單提供存檔、讀檔、設定及返回標題。讀檔或返回標題可能要求取消優先的確認。
合戰期間停用存讀檔；合戰結束後以結果對話框的明確按鈕返回策略畫面。
暫停時送出的策略指令在下一個實際遊戲日執行，不會因預覽或讀取 UI 而立即修改核心。
歷史選擇、使者與其他強制對話框必須透過其原生控制項處理，不能以 Escape 跳過。
