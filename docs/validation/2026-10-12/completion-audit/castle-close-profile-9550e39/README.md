# Clean 955 close-view FPS and CPU profile

This is one unchanged strict-60 close-view case on clean commit `9550e397568ff448689bc5904ec0651b04bfe717`, followed serially on the same sim2 RTX 5070 Ti/Vulkan host by a separate 10-second CDP CPU profile. Both used the same built source, 29 verified patched Pixi dependency files, 1920×1080 viewport, paused canonical 120-army workload, close-camera movement, and real WebGL. The strict case was selected as exactly one original test by the final `--list` control. The two earlier list attempts selected multiple tests because SSH stripped a multiword grep argument; their complete logs remain preserved. No source, rule, threshold, or baseline changed.

The original 30,057.1 ms case failed its unchanged `averageFps >= 60` assertion at **33.2367 FPS** (998 frame intervals; slow-frame FPS 27.7778; frame-time p95 36 ms). State equality, actual WebGL, regional/army population, mounted/visible army, and duration checks before the FPS assertion executed. Later original assertions for slow-frame FPS, p95, resources, and LOD did **not** execute. Their raw values are available in the attached measurement, but they are not counted as original-case passes. The 69,333,042-byte original trace remains on sim2 at the exact path in `manifest.json` with SHA-256 `6481796e2a62a30f2e61dc24dbbfd6ffc783e90a495356cbe334ad61ab189236`; it is not copied into this compact package.

The separate 10,069.2 ms profile measured 32.5746 FPS (327 frame intervals; slow-frame FPS 27.6243; p95 36.2 ms). Same-page WebGL was RTX 5070 Ti/Vulkan before and after. Core state, exported command log, map resource counters, and paused driver ticks were checked equal/zero independently. This profile is a diagnostic, not another 30-second acceptance result. Its 10,215 CDP samples were mapped through this build's source maps. Attribution is sampled main-thread CPU time, not wall-clock FPS or function call counts.
