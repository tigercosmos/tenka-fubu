This is a bounded **diagnostic**, not an adopted color-vision test change. On scoped source `e4e5521217aa14d0765b5aeb71ab2c7fd687640f`, the unchanged achromatopsia test had previously failed exact CDP restoration by 9 full-page RGBA pixels. The two proposed normalization controls failed. The original `e2e/color-vision-map.spec.ts` was restored after them; the final 1,633-file source inventory reports no mismatches or extra files. No product CSS, visual baseline, pixel tolerance, gameplay rule, or deadline changed.

The five baseline frames never reached consecutive equality in the fixed sample. The last three restored frames matched each other, but none matched a baseline frame. This does **not** prove that a common stable state is impossible or diagnose Chromium's internal cause. The test shows that neither of these bounded normalization approaches establishes exact restoration. The earlier [paint-owner evidence](../color-paint-owner-1e40539/README.md) contains one untouched no-CDP pair with exact equality, so screenshot drift is run-specific. The full-page oracle includes HTML HUD/rail compositing as well as the map; no live animation audit was performed. A later investigation can examine capture readiness without weakening the zero-pixel assertion.

The three native `.tar.gz` files here preserve complete command/process/result metadata, merged stdout/stderr, JSON reports, observations, and all generated PNGs. The two failed runs' large traces remain on sim4 at the `remoteRoot` paths in the matching `*-inventory.json`; those inventories record each trace's exact size and SHA-256. Local verification cannot prove that external files remain present. `local-captures.tar.gz` preserves 70 exclusive local setup, transfer, source-proof, collision, run, and readback captures plus the scoped e4 delta. `sources/` preserves the original and temporary test variants and the transfer producer. The first package verifier failed because the collector archived its own capture before its `result.json` existed; those original incomplete archive bytes remain as `local-captures-incomplete-v1.tar.gz`, and the completed result was added to the final archive after the collector exited. Run `python3 verify.py` to check the final local archives, raw result classifications, diagnostic counts, source hashes, and inventory bytes.
