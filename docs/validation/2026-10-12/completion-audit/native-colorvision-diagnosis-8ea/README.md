# Color-vision framebuffer diagnosis on `8ea965a`

The unchanged full native suite reported four exact-pixel restoration failures after Chromium CDP color-vision emulation. This bounded sim2 reproduction used the original `8ea965a` runtime bundle (`index-DjGL1y7l.js`), original 60-second case and 300-second suite limits, one worker, and the same achromatopsia case. It reproduced the RED assertion: 416 pixels differed between the original screenshot and the screenshot after CDP restored `none`. The original full-suite failures were 11–17 pixels in each of four modes; this isolated run did not reproduce those exact counts.

The 416 changed pixels lie within x=10–69, y=14–63 at the top-left HUD/map edge. [Original](images/overview-none.png), [restored](images/overview-restored.png), and [difference](images/overview-diff.png) show the area. The serialized game state, command log, and canvas rectangle were equal; map diagnostics differed only in ticker timing. `elementFromPoint(30,57)` returned the Pixi canvas, but the HUD header's box-shadow extends below its hit rectangle. The owning paint layer is therefore **uncertain**; a hit target does not prove those pixels came from Pixi.

A [no-CDP first](images/first.png) and [last](images/last.png) capture changed 385 pixels in the same bounds; its [difference](images/diff.png) is retained. The no-CDP control demonstrates that the edge is time-varying independently of color emulation. After CDP restoration, twelve more five-frame map-idle waits did not recover equality: [deltas](restore-deltas.json) remained 416 initially, then 406 through the final capture. This does not identify an application color-setting defect. The test changes Chromium emulation, not a game preference, and no product or test threshold was changed.

`native-raw.tar.gz` retains all three diagnostic runs, both initial launch failures (missing SSH Node PATH, then missing Playwright browser-cache path), source/dependency before-and-after proofs, full logs, reports, screenshots and traces. The source proof matched 1,632 scoped `8ea965a` files except the pre-existing unrelated Battle semantic test overlay. Installed Pixi patch hashes matched all 29 targets before and after; these dependencies were reused, not freshly installed for this batch. Scratch diagnostic specs existed only in the isolated sim2 checkout. The original full-suite report remains in the sibling `native-full-suite-8ea965a` package. Run `python3 verify.py` here to verify the retained outcomes and coordinates.
