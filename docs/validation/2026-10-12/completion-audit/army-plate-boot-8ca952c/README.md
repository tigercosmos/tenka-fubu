# Army-plate boot wait: bounded diagnosis and exception discrimination

The original complete native suite at `9550e397` failed all three army-plate geometry cases at their shared five-second `boot()` poll. None reached its plate-layout assertions. That helper caught **every** `waitMapIdle()` exception and returned `false`, so its failure report alone could not identify the exception. The original [full-suite evidence](../fullnative-current-9550/) and its browser inventory retain the three trace ZIP hashes.

We read the retained `test.trace` from each failed case. Each shows one Playwright `Evaluate` API call containing `waitMapIdle()` beginning at about 9.31, 9.50, and 9.38 seconds of trace time. The unchanged `expect.poll` timed out 5.01 seconds later, before any returned `false` retry was recorded. The pending API calls ended later or with “Test ended.” This establishes that the historical five-second window did **not** contain repeated completed `false` polls. It does not distinguish browser entry/IPC scheduling, renderer registration, or a waiting Pixi frame promise; there is no browser-side exception capture in those traces. The original screenshots show a strategy UI, but they do not establish bridge readiness. The retained ZIPs (10,461,248 / 1,860,684 / 5,867,120 bytes) remain on sim4 and are SHA-indexed by the linked full-suite package. This package includes the three extracted `test.trace` streams and one original error context.

On a fresh isolated `4dd1a55443e6b5c134a065b192a5623a7160a8de` runtime with the same 29 pinned Pixi targets, the exact original first geometry case passed. A separate read-only observer version also passed. Its single boot attempt began at page `performance.now()` 1090.8 ms, completed at 1209.3 ms, saw `diagnostics.ready=true`, one canvas, and same-canvas `ANGLE (NVIDIA, Vulkan 1.4.312, NVIDIA GeForce RTX 5070 Ti)` after idle succeeded. The observer changed only measurement, not the default five-second poll, 60-second case, 300-second global cap, or geometry assertions. These isolated passes do not reproduce or resolve the 16-worker historical timeout.

Commit `8ca952c30a8ae007ca988fd9c3294b59d3402b14` narrows the _test boot helper’s_ retry: only the exact documented “map renderer 尚未掛載” error returns `false`; other exceptions propagate. The same `waitMapIdle()` call, `expect.poll(...).toBe(true)`, and default five-second budget remain. A test-only `about:blank` control makes the first call throw an unexpected error and the second succeed if retried. Under the former catch-all behavior, that control failed because the poll eventually resolved; the old-behavior derivative is SHA-256 `dda9109d…9f5660`. Under the adopted helper, it rejects on the first unknown error; the exact not-mounted error still retries once and succeeds. The candidate file SHA-256 is `35b9a0fc…4bd999d71`. This is observability hardening, **not** a claim that the historical pending `Evaluate` was repaired.

The final isolated run of the complete file passed **6/6**: two pre-existing pure oracles, all three original native geometry cases, and the new retry control. Its runtime was the exact `4dd1a554` production build plus one test-file overlay byte-identical to the adopted `8ca952c` file. Source/dependency checks found 1,650 scoped Git inputs and 29 pinned Pixi targets correct before build, after build, before/after the observer, old-catch control, and final candidate. The production build passed. Local TypeScript, touched ESLint, Prettier, and `git diff --check` passed. Initial setup attempts with a resetting shell PATH failed with `npm: command not found`; both complete raw logs are preserved, followed by the explicit verified launcher’s passing build. An initial TypeScript cast error, ESLint mock warning, and formatting failure were likewise retained before their corrected checks.

`manifest.json` and `selected-raw.tar.gz` preserve 22 selected remote files with their raw SHA-256, including command/process/result/report/log files for all four native runs and the observer’s attempt record. `local-raw-manifest.json` preserves 234 compressed local artifacts with both raw and compressed hashes: source snapshot manifest, source/dependency proofs, exact observer/control/candidate bytes and diffs, retained trace extracts, launchers, and all checks including failures. The one new failure trace remains on sim2 at the path and hash in `manifest.json`; bulk traces are not duplicated here. Run `python3 verify.py` in this directory to verify these selected artifacts and outcomes.
