This evidence comes from original JavaScript only. The producer freezes `fc464a4` geographic layout with SHA256 `fbf127f31dbb5d8318acdf1ff1dd8bc56b77e808ba23247b779ad74ed28c3bdd` and the existing frozen reference with SHA256 `bda5b757e2bd8a2e82c5a42fde825ebe9c846337b8a578f8413938624899d9b2`. Their preparation blocks are byte-identical. Every captured frame runs both original algorithms and compares complete observed output with float64 bits. No new Rust implementation is loaded or used to derive goldens. No GPU timing runs.
