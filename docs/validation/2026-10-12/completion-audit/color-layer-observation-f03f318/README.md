One temporary test on exact scoped source `f03f3188f5cd86590864a10e65a99123a365a689` observed Chromium during the original 1280×720 overview/achromatopsia baseline → mode → restored sequence. It made no DOM or CSS changes, took one screenshot per phase, and retained the original **zero-pixel** restoration assertion. The test ended RED: the mode changed all 921,600 pixels, then the restored image differed from baseline by **508** pixels, all within x=10–69/y=14–63 at the upper-left HUD/rail edge. The temporary E2E file was removed afterward; the final scoped source inventory checked 1,633 inputs with no mismatch or extra file. No product code, baseline, threshold, or deadline changed.

At all six observations before and after those screenshots, `document.getAnimations({ subtree: true })` returned zero animations and reduced motion was active. Computed HUD, rail, pseudo-element, canvas, resource, and realm-button style/geometry records, plus focus, did not change across observations. HUD and rail computed animation durations were `0s`; full game state and command-log hashes matched across phases. `performance.getEntriesByType('paint')` returned only unchanged first-paint and first-contentful-paint entries, so it does not time these later captures.

The pinned Playwright CDP protocol defines `Layer.paintCount` as the number of times a layer has painted. The two layers sized like the HUD and rail retained their geometry while each count advanced from 1 to 2 during the mode transition and 2 to 3 during restoration. `LayerTree` emitted 84 tree-change events and no `layerPainted` event. Geometry associates those layers with the HUD/rail region, but no backend node ID was present to prove ownership. Together with static computed styles, this supports a **browser paint/compositing hypothesis** for this run rather than an active CSS animation. It does not establish Chromium's internal cause. Enabling `LayerTree` can itself affect scheduling or paint, and this was one instrumented run; the earlier uninstrumented outcomes remain separate evidence.
