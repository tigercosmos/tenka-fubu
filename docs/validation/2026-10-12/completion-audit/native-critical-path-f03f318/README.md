# Native full-suite critical-path experiment — `f03f318`

This tranche **did not adopt a runtime reduction**. The one-case control for the proposed event-scale virtual-RAF comparison failed before the event: the native `speed-5` button resolved as visible and enabled, but Playwright's original 500 ms click did not complete its visible/enabled/stable actionability wait. An exploratory instrumented-original copy failed at the same call. The virtual-RAF candidate was **never run**. Both controls used `VISUAL_GPU` unset (the default headless-shell path), so they are not an exact environment reproduction of a GPU-flagged full-suite campaign. The raw failures remain on `sim2`; no threshold, assertion, fixture, baseline, or product source was changed.

The retained full-suite reports justify testing this area but do not measure a successful optimization. The same-source 4-worker and 8-worker campaigns in `native-concurrency-ecba08b` each hit the original 300 s global deadline. The 8-worker run dispatched 254 of 364 cases and left 110 undispatched; its 45 nonpolicy responsive cases consumed 314.3 worker-seconds, 25 four-region cases 230.3, 15 policy responsive cases 200.6, and 15 mandatory overlay cases 175.1. The earlier `native-full-suite-1464146` 16-worker report, on a different revision, spent 443.9 worker-seconds on 14 completed Okehazama scale cases (28.9–34.0 s each); its 1.5-scale case had not started. The higher-worker report has greater cost for shared passes, consistent with contention: 161 shared passing cases consumed 977.4 worker-seconds at four workers and 1547.2 at eight. These are report-derived costs, not isolated speedups. Compact calculations are in `raw/cost-summary.json.gz`; canonical full reports remain in [`native-concurrency-ecba08b`](../native-concurrency-ecba08b/) and [`native-full-suite-1464146`](../native-full-suite-1464146/).
