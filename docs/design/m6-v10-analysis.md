# M6-V10 戰略分析圖層

玩家需要在同一張地圖比較領域、道路、補給與城池。既有 `analysisOverlay` 容器沒有內容，
`analysisMode` 也沒有控制介面。本階段加入互斥的分析主題、同步圖例與透明度控制。

## 狀態與更新

`uiStore` 保存 `analysisMode` 與 `analysisOpacity`。模式沿用 04 §4.6 的六個值：
`none`、`faction`、`supply`、`roadCapacity`、`terrainAdvantage`、`castleDefense`。
這兩個欄位不進 `GameState`、存檔或 Command；切換不推進日期，也不消耗亂數。

`MapCanvasHost` 把最新呈現設定送入 renderer。非同步初始化完成後，renderer 套用最新設定，
避免載入素材期間的模式切換遺失。renderer 依目前主題的資料簽章重畫；日期本身不觸發重畫。
透明度只修改容器或既有紋理的 alpha。切換主題先清除前一主題的物件。

## 圖例與資料邊界

| 主題 | 呈現                                             | 資料邊界                                              |
| ---- | ------------------------------------------------ | ----------------------------------------------------- |
| 勢力 | 陸地限定的郡域、郡界與勢力界線；勢力名與簡化部隊 | 領域使用既有 Voronoi 柵格；勢力名位置以城座標質心近似 |
| 補給 | 部隊周圍的等級環；危急時雙環                     | 存糧天數；正常 ≥7 日、短缺 3–6 日、危急 <3 日         |
| 通行 | 道級線寬與海路線型                               | 道級表示既有行軍速度等級；不表示未建模的兵員吞吐量    |
| 地形 | 平城單環、山城雙環                               | 目前城池地形欄位；不推算全地圖戰術加成                |
| 防禦 | 耐久比例環、本城雙環與支城單環                   | 耐久比例；完整 ≥50%、受損 30–49%、危急 <30%           |

圖例使用與繪圖相同的顏色常數。文字與線型說明補足顏色；勢力辨識沿用旗型與城格刻痕。
勢力模式的正常部隊縮為 6 px 記號：友軍圓形加內環、敵軍三角形、中立軍菱形。
選取、缺糧、交戰與圍城部隊保留完整棋子與警告。
所有新增文字進 `zh-TW.ts`，並重建字型子集。

## 操作與鍵盤

`LayerControl` 提供六個互斥選項。切換後立即更新圖例，透明度以 0–100% 控制。
`Alt+1` 至 `Alt+5` 對應五個分析主題；再按相同鍵退出。原速度鍵 `1/2/3` 保留。
輸入框、選單與 modal 開啟時不攔截分析快捷鍵。

04 §3.13.2 與 11 §3.16 對 `Tab` 的用途衝突。依規格優先序採用 04 的勢力圖切換，
僅在焦點位於地圖或頁面背景時生效。控制項上的 `Tab` 與所有 `Shift+Tab` 保留瀏覽器焦點導航。

## 驗收

單元測試驗證主題互斥、透明度範圍、資料簽章、圖例與快捷鍵。renderer 測試驗證紋理銷毀與靜態層計數。
瀏覽器測試比較切換前後遊戲狀態，確認新主題非空，並驗證三段縮放的必要圖層。
視覺基準須人工檢視；不能用整體 1% 容忍取代細道路與圖層存在檢查。
